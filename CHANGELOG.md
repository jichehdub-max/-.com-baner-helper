## [1.0.7] - 2026-02-11

### 🎉 Основные изменения

#### ✨ Новые возможности

**1. MP4 поддержка и увеличенный лимит файлов** 🎬
- ✅ Полная поддержка MP4 видео в баннерах (наравне с GIF)
- ✅ Убраны ограничения на размер файла - теперь до 50+ МБ
- ✅ Автоопределение типа файла (GIF или MP4)
- ✅ Динамическое имя файла (banner.gif или banner.mp4)
- ✅ Предупреждения для больших файлов (>20 МБ, >50 МБ)

**2. Python скрипты для сжатия GIF** 🐍
- ✅ `compress-gif.py` - базовое сжатие через Pillow
- ✅ `compress-gif-advanced.py` - продвинутое сжатие через ffmpeg + gifsicle
- ✅ Параметры: quality, max-size, width, height, fps
- ✅ Красивый вывод с эмодзи и статистикой
- ✅ Подробная инструкция в `GIF-COMPRESSION-GUIDE.md`

**3. Кастомные шрифты** 🔤
- ✅ Загрузка TTF шрифтов через drag & drop
- ✅ Чекбокс "Кастомный шрифт" в разделе кастомных тем
- ✅ Сохранение шрифта в base64 в chrome.storage
- ✅ Применение ко всему сайту через @font-face
- ✅ Автоматическая загрузка при старте

**4. Улучшенная поддержка Shadertoy шейдеров** ✨
- ✅ WebGL 2.0 с fallback на WebGL 1.0
- ✅ Все Shadertoy uniforms (iTime, iResolution, iMouse, iDate, и т.д.)
- ✅ Автоматическая генерация 256x256 noise текстуры для iChannel0-3
- ✅ Автозамена texture() на texture2D() для WebGL 1.0
- ✅ Синхронизация версий шейдеров

**5. Multipass рендеринг (Buffer A/B/C/D + Image)** 🔥
- ✅ Парсинг Shadertoy кода с маркерами (// Buffer A, // Image)
- ✅ Создание отдельных программ для каждого буфера
- ✅ Ping-pong framebuffers для temporal reprojection
- ✅ Предыдущий кадр буфера в iChannel0
- ✅ Результаты буферов в Image шейдере через iChannel0-3

**6. Прозрачность фона для кастомных тем** 🎨
- ✅ Слайдер прозрачности фона (0-100%)
- ✅ Применяется к градиентному и обычному фону
- ✅ Использует hexToRgba() для конвертации
- ✅ Сохраняется вместе с темой

### 🐛 Исправленные баги

### Режим отладки
Для просмотра перехваченных пакетов:
```javascript

window.__itdDebugMode = true

// Теперь при сохранении запрос остановится
// Смотри данные в консоли
// Для продолжения:
window.__itdContinue = true
```

## [1.0.4] - 2026-02-09

### 🎨 Новые возможности

#### Кастомные темы
- **Создание собственных тем** с настройкой цветов:
  - Основной цвет (primary) - для акцентов и кнопок
  - Вторичный цвет (secondary) - для градиентов
  - Цвет фона (background) - основной фон страницы
- **Автоматический контраст текста**: система определяет яркость фона и выбирает белый или чёрный текст для максимальной читаемости
- **Градиентный режим**: плавная анимация фона с переливами (15 секунд, 3 ключевых кадра)
- **Сохранение тем**: все кастомные темы сохраняются локально и доступны в любое время

#### Улучшенный интерфейс
- **Система вкладок** в панели тем:
  - Вкладка "Темы" - выбор готовых тем и создание кастомных
  - Вкладка "Шейдеры" - работа с WebGL эффектами
- **Новое расположение панели**: кнопки теперь в центре правой стороны экрана (на уровне постов)
- **Улучшенная визуализация**:
  - Активные кнопки светятся градиентом в цвет темы
  - Неактивные кнопки в тёмных тонах фона
  - Плавные переходы и анимации

#### Новые шейдеры
- **Dark Hole** - вращающаяся чёрная дыра с цветными кольцами
- **Stars** - мерцающие звёзды на тёмном фоне (50 звёзд)
- **Sky** - градиентное небо с процедурными облаками

### 🔄 Изменения

#### Темы
- Все 6 готовых тем теперь с градиентными анимациями:

  - Green - зелёные оттенки
  - Red - красные тона
  - Default - оригинальные цвета сайта (без изменений)
- Улучшена плавность анимации градиентов (было 10s ease, стало 15s ease-in-out)

- Высота контента панели адаптирована под вкладки (calc(100vh - 130px))
- Добавлена поддержка input[type="color"] для выбора цветов

- Автоматическое определение контрастного цвета текста для любого фона
